# burgers_rom

Reduced-order models for the 1D inviscid Burgers' equation, built on snapshots
generated by `FOM/burgers1d`.

## Layout

```
ROM/burgers_rom/
├── src/
│   └── burgers_rom/
│       ├── __init__.py
│       ├── snapshots.py       # build/save/load FOM snapshot matrices
│       ├── pod.py             # standard POD basis + truncation
│       ├── spod.py            # shifted POD (co-moving frame), built on sPOD/lib
│       ├── galerkin.py        # Galerkin projection onto a reduced basis
│       ├── rom_solver.py      # time integration of the reduced system
│       ├── hyperreduction.py  # DEIM/EIM for the nonlinear term
│       ├── error_metrics.py   # FOM-vs-ROM error metrics
│       └── config.py          # reproducible run configuration
└── pyproject.toml
```

## Install (editable, for development)

Install both packages into the same environment — `burgers_rom` consumes
`burgers1d` for snapshot generation but does not declare it as a hard
dependency, since it's a sibling package in this repo rather than a published
one:

```bash
pip install -e ../../FOM/burgers1d
pip install -e .
```
